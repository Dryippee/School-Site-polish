HOW TO CHANGE THE BACKGROUND
============================

1. Find any image you want as your background
2. Save it as "bg.png" inside this folder (backgrounds/bg.png)
3. Go to chrome://extensions and click the reload icon on this extension
4. Refresh your StudentVue / Canvas / iReady page

The image will automatically scale to fit your screen.

To go back to the default background, just delete the "bg.png" file
from this folder and reload the extension.
