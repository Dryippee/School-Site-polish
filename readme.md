**School-Site-Polish**

Change the way you work with this brand new Chrome Extension built with students at mind!

HOW TO USE THIS EXTENSION
============================

1. Download the Repository on your Device (As a Zip)
2. Go to chrome://extensions and toggle Developer Mode
3. Select Load Unpacked at the top of the page
4. Select "School Site Polish" --> "StudentVue-UI" and enjoy!



HOW TO CHANGE THE BACKGROUND
============================

1. Find any image you want as your background
2. Save it as "bg.png" inside this folder (personalization/bg.png)
3. Go to chrome://extensions and click the reload icon on this extension
4. Refresh your page

The image will automatically scale to fit your screen.
