HOW TO CHANGE YOUR PROFILE PICTURE
====================================

1. Find any image you want as your profile picture
2. Save it as "pfp.png" inside this folder (profiles/pfp.png)
3. Go to chrome://extensions and click the reload icon on this extension
4. Refresh any school site page

Recommended size: 512x512 pixels or square aspect ratio.
The image will be cropped into a circle automatically.

To go back to the default profile picture, delete the "pfp.png"
file from this folder and reload the extension.
